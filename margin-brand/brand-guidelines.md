# Margin brand guidelines

## Identity overview

**Margin** is a private, focused editor for notes, plain text, Markdown and code. It belongs to the **Dr. Claw Development** family but should not feel theatrical or gimmicky. The identity should communicate precision, control and privacy.

## Chosen direction

**Redline** uses a simplified document symbol with one red margin bar. The mark works because it is:

- directly related to writing and editing,
- easy to recognize at small sizes,
- visually compatible with a dark-mode developer tool,
- clearly connected to the parent family's black / red / metallic palette.

## Core assets

- **Primary symbol:** document icon with red margin
- **Primary wordmark:** MARGIN with red lead bar
- **Monogram:** angular M with a red lead bar
- **Tagline:** Private notes and code, in one place.

## Color usage

- Use **Villain Red** `#E10606` for meaningful emphasis: primary buttons, active highlights, focused states and the redline itself.
- Use **Shadow Black** `#0B0B0B` and **Charcoal** `#111111` for the overall canvas and chrome.
- Use **Metallic Silver** `#8F959C` for logo rendering, borders, inactive structural elements and small decorative highlights.
- Use **Highlight White** `#EDEDED` for readable text and high-contrast icon strokes.
- Do **not** flood the UI with red. Red is a signature accent, not the entire interface.

## Do

- Keep the interface compact and practical.
- Preserve strong contrast and readability.
- Use the source SVGs for derivatives.
- Keep the icon simple in small contexts.
- Treat `/margin-brand/` in the repo as the canonical brand source.

## Don't

- Do not add cartoon illustrations or copy Inspector Gadget / MAD imagery.
- Do not reintroduce the old blue accent as the primary action color.
- Do not add ornamental textures, glows or motion beyond light accents.
- Do not stretch or recolor the icon arbitrarily.
